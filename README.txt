# VYRA Full-Stack Application

This project bundles the dynamic user authentication backend mapped onto the raw modern HTML profile.

## Setup Instructions

1. Extract the zip archive contents completely.
2. Ensure Node.js is configured on your environment.
3. Open a terminal inside the project directory and install system dependencies:
   ```bash
   npm install
   ```
4. Start the application execution flow:
   ```bash
   npm start
   ```
5. View the running build locally inside your browser context:
   http://localhost:3000
